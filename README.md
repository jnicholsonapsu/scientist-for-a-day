# Scientist for a day

This is a collection of resources for the Scientist for a Day event where we explore make art using math and coding.

## After the event

Here are some resources if you are interested in learning more about math, art, Processing, and programming.

* The [Mathematical Art Galleries](https://gallery.bridgesmathart.org/) from the annual Bridges Conference on mathematical connections in art, music, architecture, and culture; and the annual Joint Mathematics Meetings, the world's largest mathematics gathering. 
* Processing
    * The [Processing website](https://processing.org/) is the source for everything about Processing. From here, you can [download](https://processing.org/download) Processing, access documentation, find tutorials, and join the Processing community.
    * Daniel Shiffman's learning resources for Processing
        * Books
            * **Learning Processing, 2nd edition**, is an introductory book specifically geared towards people who do not know how to program. It covers how to program and how to use Processing.  Unfortunately, the author was not allowed to make this book available for free, so most people buy a copy.  You may be able to find it in some libraries.
                * [Amazon](https://www.amazon.com/Learning-Processing-Second-Edition-Programming/dp/0123944430)
                * [Book website](http://learningprocessing.com/)
            * **Nature of Code** is another book covering more advanced coding techniques and concepts. The entire book is available online for free, although you can purchase it if you wish.
                * [Book website](https://natureofcode.com/)
                * [Amazon](https://www.amazon.com/Nature-Code-Daniel-Shiffman/dp/1718503709)
        * **Coding Train** is Daniel Shiffman's website and YouTube channel covering all aspects of Processing.  It contains videos for everyone, from the complete beginner to those with more experience.
            * [Website](https://thecodingtrain.com/)
            * [Youtube channel](https://www.youtube.com/c/TheCodingTrain)
